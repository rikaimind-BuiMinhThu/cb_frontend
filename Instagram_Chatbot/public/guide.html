【EC Chatbot実装】

Amazon Pay利用の判定

今この人が Amazon Pay で支払おうとしているかを見分けます。当たると連携モードで起動し、複写式の入力項目へ自動入力されます。

購入ページ（LP）でお客様がAmazon Payを利用しているかを判定します。検出されるとチャットボットはAmazon Pay連携モードで起動し、複写式の入力項目へ自動入力が行われます。

値の説明
  • JSコードで判定 — 自分で true を返す JavaScript を書きます。
  • URLパラメータで判定 — アドレスに特定のパラメータ名があるか見ます。値は入れません。
  • DOMセレクターで判定 — ページ上に特定の要素があるか見ます。1行に1件。カンマ区切りは使いません（起動ボタンセレクターとは違います）。

判定用JSコード: true（真）を返すJavaScriptを記述してください。

判定用URLパラメータ: URLに含まれるパラメータ名を1行に1件ずつ入力してください。

判定用DOMセレクター: ページ上の要素を示すCSSセレクターを1行に1件ずつ入力してください。

オートフィル完了の判定

氏名や住所が書き終わるまで待ってから、チャットを開くかどうかです。

【EC Chatbot実装】

オートフィル完了の判定

Amazon Pay が LP の氏名・住所欄へ値を書き終わるまで、チャットの起動を遅らせることができます。待たないと、空のまま起動することがあります。

Amazon Pay連携時、LPのフォームへ住所・氏名などが自動入力されるまで時間がかかることがあります。入力完了を待ってからチャットボットを起動したい場合に設定します。未設定の場合は検出後すぐにチャットボットを起動します。

値の説明
  • 待機しない（即時起動） — Amazon Pay を検出したら、すぐチャットを開きます。
  • DOMセレクターで判定 — 指定した入力欄に値が入るまで待ちます。

完了判定用DOMセレクター

「値が入ったら準備完了」とみなす欄です。姓など、Amazon Pay が埋める項目を指定します。

LPフォームの入力欄セレクターを1行に1件ずつ入力してください。指定した欄に値が入力されるまでチャットボットの起動を待ちます。

値の入れ方
  • 1行に1件。カンマ区切りは使いません。
  • 表示されていて、Amazon Pay が値を入れる欄を選びます。

カート別サンプル

Ec-Force input#order_shipping_address_attributes_name1
サブスクストア input#jsUkProfileFamilyName
リピートPLUS input#ctl00_ContentPlaceHolder1_ucInputForm_rCartList_ctl00_tbOwnerName1

ポーリング間隔（ms） / 最大ポーリング回数

完了判定をするとき、何ミリ秒ごとに欄を見るか、何回まで待つかです。届かなければ処理を止めます。

LPページでAmazon Payの読み込み完了を確認する際の、ポーリング間隔（ミリ秒）です。

Amazon Payの読み込み完了を確認する最大ポーリング回数です。この回数に達しても完了しない場合は処理を中断します。

サブスクストア間隔 200 / 最大 20
リピートPLUS間隔 200 / 最大 20

使う

LPのCTA。固定フッターの購入ボタン、#target_cart へ飛ぶ画像ボタンなどです。

5. 設定後の確認方法

シナリオを保存したあと、LPで次を確認します。

【説明用Mockup】
ElementsConsole

> document.querySelector('#lbChangePayment')

<a id="lbChangePayment" ...>

> document.querySelector('#no-such-id')

null

成功の目安

  • Amazon Payログイン後に、連携モードでチャットが起動する
  • 氏名などが自動入力されるまで待ってから起動する（完了判定を入れた場合）
  • LPのCTAをクリックしてチャットが開く
  • 入力エラーを出したとき、チャットにエラー文が届く

うまくいかないとき

  • Console が null → セレクタが違う
  • length が 2以上 → 対象が広すぎる
  • .error_inline が空のまま → 実エラーを出して再確認
  • Amazon Pay判定が動かない → キャンセルボタンID、または URLパラメータ名を確認
